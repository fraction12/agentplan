The task queue your AI agents are missing

Installed via PyPI  ·  Works with Claude Code, Codex, OpenClaw, Cursor, and any CLI agent

How it works

01
agentplan create my-project

Create

Define a project with tickets, priorities, and dependencies in seconds.

02
agentplan next my-project

Claim

Agents grab the next unblocked ticket automatically — no coordination overhead.

03
agentplan ticket done my-project 1 --agent dash

Ship

Mark complete with attribution. Dependencies auto-unblock downstream tickets.

Why agentplan

⚡

Zero dependencies

Pure Python stdlib. pip install and go. No heavy runtimes, no package soup.

🔗

Dependency graph

Tickets auto-unblock when their blockers close. The queue self-manages.

🤖

Agent-agnostic

Works with any agent, any framework, any model. No vendor lock-in.

📊

Built-in dashboard

Real-time web UI with SSE live updates. See project state at a glance.

🔒

Parallel-safe

SQLite with BEGIN IMMEDIATE. No double-claims. Safe across concurrent agents.

🏷️

Rich metadata

Priority, tags, subtasks, due dates, audit logs. Everything you need to track.

See the CLI

zsh — agentplan demo
$ agentplan create sprint-1 Created project 'sprint-1' (sprint-1)   $ agentplan ticket add sprint-1 "Build API" --priority high --tag backend Added ticket #1: Build API [priority: high]   $ agentplan ticket add sprint-1 "Write tests" --priority medium --tag testing Added ticket #2: Write tests [priority: medium]   $ agentplan depend sprint-1 2 --on 1 Ticket #2 now depends on: [1]   $ agentplan next sprint-1 📋 sprint-1: [1] Build API ○ (priority: high)   $ agentplan ticket done sprint-1 1 --agent dash --note "API shipped" ✓ Ticket #1: Build API → done [API shipped] (by dash)   $ agentplan status sprint-1 1/2 done, 0 blocked, next: [2] Write tests
