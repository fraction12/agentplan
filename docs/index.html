How it works

01
agentplan create my-project

Create

Define a project with tickets, priorities, and dependencies in seconds.

02
agentplan next my-project

Claim

Agents grab the next unblocked ticket automatically — no coordination overhead.

03
agentplan ticket done my-project 1 --agent dash

Ship

Mark complete with attribution. Dependencies auto-unblock downstream tickets.

Why agentplan

⚡

Zero dependencies

Pure Python stdlib. pip install and go. No heavy runtimes, no package soup.

🔗

Dependency graph

Tickets auto-unblock when their blockers close. The queue self-manages.

🤖

Agent-agnostic

Works with any agent, any framework, any model. No vendor lock-in.

🏷️

Roles & Routing

Define roles, register agents, tag tickets. agentplan routes work to the right tool automatically.

🪝

Event Hooks

Fire webhooks, commands, or agent chains when tickets complete. Build autonomous pipelines.

🔄

Stale Claim Handling

Claim timeouts and auto-reaping. Crashed agents don't block the queue — tickets self-heal.

📊

Dashboard Control Plane

Start/Stop work, Kanban board, Agents page, review panel. Real-time SSE updates.

🔒

Parallel-safe

SQLite with BEGIN IMMEDIATE. No double-claims. Safe across concurrent agents.

🔍

Auto-Detection

Scans for installed AI tools and registers them. Auto-generates project context by scanning your codebase.

📄

Project Context

Link projects to codebases. Agents auto-generate .agentplan.md context files — like CLAUDE.md, but for your task queue.

Ship to CI/CD in minutes

01
uses: fraction12/agentplan/actions/setup@v0.7.1

Setup Action

Install agentplan in any GitHub Actions workflow with a single line.

02
agentplan issue import my-project --label agentplan

Import Issues

Pull labeled GitHub issues directly into your agentplan project as tickets.

03
uses: fraction12/agentplan/actions/run-chain@v0.7.1

Run Chain

Execute your agent chain headlessly in CI. Publishes a run summary to the workflow.

Mission Control

Project cards with SVG progress rings showing real-time completion at a glance.

6-Column Kanban
