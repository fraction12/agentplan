⚡ agentplan · lightweight AI project tracker

Structured project tracking for AI agents

Plan and ship work with a simple, dependency-aware ticket workflow. agentplan keeps multi-project tasks organized, agent-assignable, and fully CLI-native.

Why teams use agentplan

Multi-project workflows

Track active work across multiple repos and initiatives without context loss.

Ticket-level tracking

Create, prioritize, and close granular tickets so agents always have clear next steps.

Agent assignment

Assign tickets to specific agents and keep ownership explicit from start to done.

Progress logs

Attach concise status updates to each ticket for transparent execution history.

Dependency resolution

Define dependencies so blockers are visible and sequencing stays deterministic.

CLI-first by design

No heavy setup, no platform lock-in — just fast commands that fit existing toolchains.

CLI example

# initialize agentplan in your project
agentplan init

# add a ticket
agentplan add ticket "Build landing page" --project "agentplan-v03" --assignee "dash"

# fetch the next actionable ticket
agentplan next

# mark ticket complete
agentplan done T7
